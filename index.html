COMANDOS BÁSICOS

Tu caja de herramientas

Descubre para qué sirve cada comando de Git.

01
REPOSITORIO

git init

Inicializa un nuevo repositorio local en la carpeta actual para comenzar a controlar las versiones de tu proyecto.

$ git init
02
DESCARGA

git clone

Descarga una copia de un repositorio remoto para que puedas trabajar con sus archivos en tu computadora.

$ git clone URL
03
CONTROL DE CAMBIOS

git add

Selecciona los archivos modificados que deseas preparar para incluirlos en el próximo commit.

$ git add .
💡

¡Consejo de programador!

Después de preparar tus cambios con git add, puedes guardarlos en el historial con git commit.
